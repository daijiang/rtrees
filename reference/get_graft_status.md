# Extract grafting status information as a data frame

Extract grafting status information as a data frame

## Usage

``` r
get_graft_status(tree)
```

## Arguments

- tree:

  A phylogeny generated by `get_tree(...)`, or a `multiPhylo` of such
  phylogenies.

## Value

A tibble with three columns: tip_label, species, and status. For a
`multiPhylo`, the tables of all phylogenies are stacked and an extra
leading column, `tree`, gives the name (or index) of each phylogeny. If
no grafting information is available, an empty tibble with these columns
is returned.
